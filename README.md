## 🚀 Features

- User authentication & secure login
- Browse live & upcoming cricket matches
- Create your fantasy team (Pick 11 players)
- Select Captain & Vice-Captain for bonus points
- Join contests & compete with others
- Real-time team preview in interactive modal
- Responsive UI with Tailwind CSS

---



## 🛠️ Tech Stack

⚛️ React.js – Frontend framework

🔄 Redux Toolkit – State management

🎨 Tailwind CSS – Styling

⚡ Vite – Fast bundler

🌐 Axios – API integration

---

## ⚙️ Installation & Setup

1. Clone the Repo

```bash
git clone https://github.com/ankitmittal4/Cric11-frontend.git
cd Cric11-frontend
```

2. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm run dev
```

4. Build for production

```bash
npm run build
```
